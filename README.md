# Woodique

A React + Vite storefront for Woodique, a brand focused on thoughtfully crafted wooden tray sets and everyday home pieces.

## Tech stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Code quality

```bash
npm run lint
```

## Project structure

- `src/components/` — shared storefront sections and UI components
- `src/pages/` — page-level views
- `public/images/` — public brand and website assets

This repository contains the Woodique storefront. Keep the original Eman Jewelers repositories separate and unchanged.
